Belette 3D pour iPad — PWA

1. Publier le contenu de ce dossier sur un hébergement HTTPS statique.
2. Ouvrir son URL dans Safari sur iPad.
3. Partager > Sur l’écran d’accueil > Ajouter.
4. Maintenir l’icône puis la déplacer dans le Dock.

Important : les modules Three.js sont actuellement chargés depuis esm.sh et nécessitent une connexion réseau. Le fonctionnement hors ligne complet n’est pas garanti. Ne pas importer de données patient identifiantes dans ce prototype non validé.
